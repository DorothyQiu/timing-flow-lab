# CHIPSTITCH timing experiments

Small RTL and ASIC implementation experiments comparing clock models for timing
between a station block and a user block. The flow uses Synopsys Design Compiler
for synthesis and Cadence Innovus for placement, clock tree synthesis (CTS), and
routing, with timing reports before CTS, after CTS, and after routing.

| Experiment | Clock model |
| --- | --- |
| `demo1` | Baseline: a single primary clock. |
| `demo2` | Separate user clock with a guessed source latency; `USER_CLK_OFFSET` defaults to 0.7 ns. |
| `demo3` | Divide-by-one generated user clock derived from the station clock pin; CTS targets the primary clock. |

All three synthesis scripts constrain the primary clock to a 5 ns period.

## Layout

- `design/`: RTL, including `top_demo1.v`, `top_demo2.v`, `top_demo3.v`, shared blocks, and `top.v`.
- `tb/`: RTL testbenches for demo1/demo2 and post-synthesis/post-PnR testbenches for demo1.
- `scripts/`: per-demo `syn_*.tcl` and `innovus_*.tcl`, shared `mmmc.tcl`, and simulation Tcl scripts. Authored timing constraints live in the synthesis Tcl scripts.
- `makefile`, `cds.lib`, `hdl.var`: flow targets and Cadence simulation configuration.
- `netlist/demo*/`, `report/demo*/`, `timingReports/`: generated outputs, excluded from Git. Exported `.sdc` files are regenerated by synthesis.

## External tools and technology

Provide licensed installations of Design Compiler (`dc_shell`), Innovus
(`innovus`), and Cadence simulation tools (`ncvlog`, `ncelab`, `ncsim`; SimVision
for GUI use), plus GNU Make.

Technology files are intentionally excluded pending confirmation of publication
rights. Obtain authorized copies independently:

- `include/gscl45nm.v`: standard-cell Verilog model for gate-level simulation.
- `lib/gscl45nm.lef` and `lib/gscl45nm.tlf`: physical/library inputs referenced by Innovus scripts. The local `lib/` also contains `gscl45nm.map` and `gscl45nm.v`; the entire directory remains excluded.
- `gscl45nm.db` for synthesis and `gscl45nm.lib` for MMMC timing, from the external NCSU45PDK/FreePDK45 OSU library installation.
- `dw_foundation.sldb` and `standard.sldb`, supplied with the Synopsys tool environment.

Update the site-specific library directory in `scripts/syn_demo*.tcl` and
`scripts/mmmc.tcl` to your authorized installation. The current scripts reference
`/home/scf-22/ee577/NCSU45PDK/FreePDK45/osu_soc/lib/files`.
The MMMC RC corner is minimal and has no capacitance table configured.

## Flow and current limitations

After configuring dependencies and resolving the source issues below, intended
commands from this directory are:

```sh
make syn DEMO=demo1
make pnr DEMO=demo1
# Select demo2 or demo3 with DEMO=...
USER_CLK_OFFSET=0.4 make syn DEMO=demo2
make sim DEMO=demo1
make sim_syn DEMO=demo1
make sim_pnr DEMO=demo1
```

This is an experimental source snapshot, not a validated reproducible flow:
the current `station.v` and `user_mult.v` ports do not match their top-level
instantiations. There is no demo3 testbench or demo2 gate-level testbench.
Existing testbenches use a 10 ns clock, unlike the 5 ns synthesis constraint.
The RTL simulation target compiles all testbenches, including one that includes
the external cell model and a generated synthesis netlist. Simulation therefore
needs further source/flow reconciliation. Repository preparation did not run EDA
tools or modify the existing RTL and scripts.
